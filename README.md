# SQL

Proyecto de SQL. Base de datos de una universidad con alumnos, profesores, cursos y notas.

## Archivos
- 01_create_tables.sql -> crea las tablas
- 02_insert_data.sql -> datos de prueba
- 03_queries.sql -> las consultas del ejercicio

## Como ejecutarlo
Ejecutar los scripts en orden (01, 02, 03) en MySQL.

## Consultas
1. Media de notas por profesor
2. Nota mas alta de cada alumno
3. Alumnos y sus cursos
4. Cursos de mas dificil a mas facil (por nota media)
5. Alumno y profesor con mas cursos en comun
